# Не устанавливается расширение ChatGPT в Chrome — установка и обновление

[Главная](README.md) · **Русский** · [English](README.en.md) · [简体中文](README.zh-CN.md)

## Chrome Web Store недоступен или расширение недоступно в регионе?

Если расширение ChatGPT не устанавливается из Chrome Web Store, страница магазина недоступна или показывает ограничение для вашего региона, этот установщик для Windows предлагает другой путь загрузки: официальный CRX через Google update service. PowerShell-скрипт проверяет подпись пакета, сохраняет extension ID `hehggadaopoacecdllhhajmbjkdcmajg` и создаёт резервные копии при обновлении. CRX — файл пакета расширения Chrome. Это независимый проект, не продукт OpenAI или Google.

Способ может помочь, если страница магазина не работает, но сервис загрузки Google доступен. Обход региональных ограничений и доступ к самому ChatGPT не гарантируются.

Поводом стал пользовательский случай: страница Web Store недоступна либо установка не проходит, а распакованная копия получает другой ID. Причина сбоя магазина не установлена; доступность может различаться. Другой ID может мешать интеграциям. Сохранение ID само по себе не гарантирует обнаружение расширения приложением, вход в аккаунт или доступ к сервису.

**CSP не изменяется.** CSP — правило браузера, определяющее, какие ресурсы разрешено загружать расширению. Скрипт сохраняет исходное правило и не исправляет ошибки CSP. В `manifest.json` добавляется только публичный `key`, если его нет. JavaScript, native host (локальный посредник между браузером и приложением), реестр, профили и политики Chrome не меняются.

## Требования и установка

Нужны Windows, Chrome и [PowerShell 7.2+](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows). Используйте `pwsh`, а не Windows PowerShell 5.1 (`powershell`). Нужен доступ к `clients2.google.com` и серверам загрузки Google, а также право записи в выбранную папку. Для папки по умолчанию права администратора не нужны.

1. Скачайте репозиторий (**Code → Download ZIP**), распакуйте и откройте терминал в его папке.
2. Выполните:

   ```powershell
   pwsh -NoProfile -File .\Install-Update-ChatGPT-ChromeExtension.ps1
   ```

3. Откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное** и выберите папку, которую напечатал скрипт, не её родительскую папку:

   ```text
   %LOCALAPPDATA%\ChatGPTforChromeInstaller\hehggadaopoacecdllhhajmbjkdcmajg
   ```

4. Проверьте ID: `hehggadaopoacecdllhhajmbjkdcmajg`.

Не удаляйте эту папку: Chrome использует файлы из неё. Подключение в браузере выполняется вручную. Это распакованная установка, а не установка под управлением Web Store.

## Запуск из PowerShell без ручного скачивания

Вставьте блок целиком в PowerShell: он скачает актуальный установщик из этого репозитория, запустит его в PowerShell 7.2+ и удалит временный скрипт. PowerShell 7.2+ должен быть уже установлен, а команда `pwsh` доступна в PATH (списке папок, где система ищет команды). Сам блок можно вставить и в Windows PowerShell 5.1.

```powershell
& {
    $pwsh = Get-Command pwsh -ErrorAction Stop
    $installer = Join-Path $env:TEMP ("ChatGPT-installer-" + [guid]::NewGuid() + ".ps1")
    try {
        Invoke-WebRequest -UseBasicParsing -Uri 'https://raw.githubusercontent.com/Const-NW/ChatGPTforChromeInstaller/main/Install-Update-ChatGPT-ChromeExtension.ps1' -OutFile $installer -ErrorAction Stop
        & $pwsh.Source -NoProfile -ExecutionPolicy Bypass -File $installer
        if ($LASTEXITCODE -ne 0) { throw "Installer failed (exit code $LASTEXITCODE)." }
    }
    finally {
        if (Test-Path -LiteralPath $installer) { Remove-Item -LiteralPath $installer -Force }
    }
}
```

Команда выполняет код из ветки `main` этого репозитория. `ExecutionPolicy Bypass` действует только для запускаемого процесса и не меняет сохранённую политику выполнения. Для передачи параметров добавьте `-Force` или `-InstallDir 'C:\Install\ChatGPT\hehggadaopoacecdllhhajmbjkdcmajg'` после `-File $installer`. При обновлении повторите блок и нажмите **Перезагрузить / Reload** в Chrome. При первой установке выполните описанный выше шаг **Загрузить распакованное**.

## Обновление и параметры

Повторите ту же команду и нажмите **Перезагрузить / Reload** на карточке расширения. Обновления ручные, задача в планировщике не создаётся. Та же версия пропускается; понижение версии запрещено даже с `-Force`.

```powershell
# Восстановить официальные файлы той же версии с резервной копией
pwsh -NoProfile -File .\Install-Update-ChatGPT-ChromeExtension.ps1 -Force

# Своя постоянная папка: указывайте её при каждом обновлении
pwsh -NoProfile -File .\Install-Update-ChatGPT-ChromeExtension.ps1 -InstallDir 'C:\Install\ChatGPT\hehggadaopoacecdllhhajmbjkdcmajg'

# Если Chrome не найден: подставьте свою версию из chrome://version
pwsh -NoProfile -File .\Install-Update-ChatGPT-ChromeExtension.ps1 -ChromeVersion '153.0.8010.54'
```

Версия в примере не является обязательной или гарантированно последней. Существующая папка должна содержать манифест с соответствующим ключом. Иначе скрипт откажется её заменять: укажите путь, который ещё не существует, и перенесите установку вручную. Заранее созданная пустая папка тоже отклоняется. На время проверки отключите старую копию; удаление расширения может удалить его локальные данные. Если уже установлена версия из магазина с тем же ID, сначала вручную решите вопрос с ней в Chrome.

## Проверки и восстановление

Перед заменой скрипт проверяет структуру CRX3, подписанный ID, ID по публичному ключу разработчика и криптографическую подпись. Это не полная проверка по всем правилам Chrome Web Store. CRX2 не поддерживается. Проверка сертификатов HTTPS включена.

При каждой замене старая папка остаётся рядом как `*.backup-<дата>-<суффикс>`. Ошибки подготовки не затрагивают прежнюю установку; при ошибке финального перемещения скрипт пытается вернуть её обратно. Резервные копии автоматически не удаляются.

Для ручного восстановления отключите расширение, переместите неудачную установку в другую папку, переименуйте нужную резервную копию точно в исходный путь, затем перезагрузите и включите расширение. Копируются файлы расширения, а не данные профиля Chrome.

## Частые вопросы: расширение ChatGPT не устанавливается

### Как установить расширение ChatGPT, если Chrome Web Store недоступен?
Выполните блок PowerShell выше, затем выберите «Загрузить распакованное». Страница магазина не нужна, но сервис загрузки Google должен быть доступен. Прямой запуск также требует доступа к `raw.githubusercontent.com`; если он недоступен, используйте заранее скачанную копию репозитория.

### Расширение недоступно в вашей стране или регионе — это поможет?
Можно попробовать загрузку через Google update service. Ограничение может распространяться и на пакет, поэтому успех не гарантируется. Установка не снимает ограничения аккаунта и не открывает доступ к ChatGPT автоматически. Причина исходного сбоя магазина не установлена.

### Кнопка «Установить» или Add to Chrome не работает — что делать?
Сначала обновите Chrome и используйте обычный профиль на компьютере, не инкогнито или гостевой режим. Альтернативная загрузка может помочь при проблеме со страницей магазина. Если установку запрещает администратор, обратитесь к нему. См. [рекомендации Google по ошибкам установки](https://support.google.com/chrome_webstore/answer/1698338?hl=ru).

### Это официальное расширение ChatGPT или сторонний аналог?
Скачивается только пакет Google для ID `hehggadaopoacecdllhhajmbjkdcmajg`; подпись разработчика проверяется до распаковки. Сам установщик — независимый проект. Другие расширения с похожими названиями он не устанавливает.

### Почему ChatGPT или Codex не видит распакованное расширение?
Одна из возможных причин — другой extension ID. Публичный `manifest.key` сохраняет исходный ID, но скрипт не исправляет настройку приложения или native host.

### Как обновлять без страницы Chrome Web Store?
Повторите команду и нажмите Reload в Chrome. Сервис загрузки Google должен оставаться доступным. Распакованная копия обновляется вручную.

### PowerShell пишет «pwsh не распознано»?
Установите PowerShell 7.2+ и откройте новый терминал. Windows PowerShell 5.1 недостаточно для самого установщика.

## Если возникла ошибка

- **Скрипт заблокирован:** после просмотра кода выполните `Unblock-File .\Install-Update-ChatGPT-ChromeExtension.ps1`, если файл помечен как скачанный. Политики организации всё равно могут запрещать запуск.
- **Ошибка сети/TLS/HTTP:** проверьте соединение и версию Chrome. Сам update service тоже может быть недоступен; зеркала не используются.
- **Не совпали подпись или ID:** остановитесь, не отключайте проверку.
- **Неверный ID в Chrome:** проверьте выбранную папку и перезагрузите нужную карточку.
- **Приложение всё ещё не видит расширение:** проверьте его собственную настройку подключения. Скрипт не ремонтирует native host.
- **Режим разработчика запрещён:** обратитесь к администратору; скрипт не обходит политики.
- **Папка занята:** закройте процессы, использующие её, и повторите. Сохраните резервные копии.
